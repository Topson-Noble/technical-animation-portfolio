8-Directional Movement: State Machine and Blendspaces

Developed a responsive 8-directional locomotion system that allows the character to move naturally in every direction.

The system uses Blend Spaces and Animation Blueprints to create smooth transitions between idle, walking, running, and strafing while keeping player input responsive.

I focused on making the movement feel fluid and reliable so it could serve as a solid foundation for third-person gameplay.

Flight System

Built a complete flight animation system that handles the character's transition from grounded movement into the air and back again.

The system includes takeoff, hovering, directional flight, and landing, all connected through Animation Blueprints and state machines.

My goal was to make each transition feel seamless while keeping the setup flexible enough to be expanded with additional flight mechanics in the future.

IK Foot Placement: Terrain Adaptation

Implemented an IK foot placement system that adjusts the character's feet to match uneven terrain at runtime.

By using line traces to detect the ground beneath each foot, the system reduces foot sliding and prevents the feet from clipping through surfaces.

This helps the character maintain more believable contact with the environment, especially when moving across slopes or irregular terrain.

Turn-In-Place

Created a curve-driven Turn-In-Place system that allows the character's torso to rotate naturally while standing still.

The system detects changes in the character's root bone offset (or facing angle) and plays the appropriate turning animation before returning to the idle state.

This small detail adds a noticeable improvement to the overall feel and realism of the character's movement.
